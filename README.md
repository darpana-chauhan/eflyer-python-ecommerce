# 🛍️ Eflyer – Python Django E-commerce Website

Eflyer is a fully functional **E-commerce Web Application** built using **Python (Django Framework)** with **SQLite** as the database.  
This project allows users to browse and purchase products from various categories like **Clothes, Jewelry, and Electronics** with smooth checkout functionality.

## ⚙️ Tech Stack

- **Backend:** Python (Django Framework)  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** SQLite  
- **Tools Used:** VS Code, Git, GitHub  

---

## ✨ Key Features

- 🛒 Add to Cart functionality  
- 👤 User Registration and Login  
- 💳 Checkout system with order summary  
- 📦 Product categories like Clothes, Jewelry, and Electronics  
- 🧾 Admin panel for managing products and users  
- 📱 Responsive and modern UI design
